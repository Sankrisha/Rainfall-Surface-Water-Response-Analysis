# Rainfall Surface Water Response Analysis

A GIS and remote-sensing project analyzing how rainfall impacts lakes, rivers, and reservoirs. The system combines precipitation datasets with satellite imagery to track surface-water surface area changes, identify drought-vulnerable water bodies, and present actionable insights through interactive dashboards.

---

## 📌 Problem Statement
Water resources are highly sensitive to fluctuating rainfall patterns. Tracking surface-water availability in real-time is essential for predicting droughts, managing water supply, and supporting agricultural and environmental planning.

---

## 🛠️ Tech Stack & Tools
* **GIS & Remote Sensing:** Google Earth Engine (GEE), QGIS, GeoPandas
* **Data & Satellite Imagery:** Sentinel-2, Landsat, CHIRPS Rainfall Data
* **Programming Languages:** Python, JavaScript
* **Dashboard & Visualization:** Streamlit / Dash, Plotly, Folium

---

## 🚀 Key Features
* **Surface Water Area Tracking:** Measures changes in water body extent across seasons using satellite indices (NDWI / MNDWI).
* **Drought Vulnerability Assessment:** Correlates rainfall dropouts with surface water reduction to identify vulnerable zones.
* **Interactive Dashboard:** Displays dynamic maps, time-series graphs, and statistical summaries for easy data analysis.
